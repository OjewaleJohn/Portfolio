# Retail Sales & Outlet Performance Analysis

## Project Overview
This project analyses a retail sales dataset containing 8,523 records across multiple products, categories, outlets and location tiers. The goal was to understand product performance, outlet performance and overall sales patterns using Microsoft Excel.

## Business Goal
The analysis was designed to answer practical retail questions such as:
- Which product categories generate the most sales?
- Which outlet types perform best?
- How does performance vary across outlet locations and outlet formats?
- What data-quality issues need to be addressed before reporting?
- Which KPIs should management monitor regularly?

## Tools Used
- Microsoft Excel
- PivotTables
- Excel formulas
- Charts and dashboard reporting
- Data cleaning and validation

## Analysis Performed
- Reviewed and structured 8,523 retail records for analysis.
- Analysed sales by product category and item type.
- Compared sales performance across outlet types and location tiers.
- Reviewed average and total sales across outlet formats.
- Built PivotTable summaries and dashboard visuals for management reporting.
- Identified missing values and inconsistent categorical labels in the dataset.
- Reviewed product and outlet fields for data-quality issues before reporting.

## Key Findings
- Fruits & Vegetables and Snack Foods were among the strongest categories by total sales.
- Supermarket Type 3 recorded the highest average sales among the outlet formats analysed.
- Performance differed significantly across outlet types, showing that outlet format is an important business-performance factor.
- The dataset contained missing values and inconsistent labels that required cleaning and standardisation.

## Data Quality Observations
The analysis identified:
- Missing values in Item Weight.
- Missing values in Outlet Size.
- Inconsistent Item Fat Content labels such as `Low Fat`, `low fat`, `LF`, `Regular` and `reg`.
- A field labelled `Sales Profit` that should be renamed to a clearer classification such as `Sales Performance Band`.
- The `Year` field should be clearly labelled based on its actual meaning before presenting it as a sales trend.

## Business Value
This project demonstrates how Excel can be used to transform retail data into clear business insights for sales monitoring, outlet comparison, KPI reporting and management decision-making.
