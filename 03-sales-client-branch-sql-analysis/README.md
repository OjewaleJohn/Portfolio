## Project Overview
This MySQL project models a business database containing employees, branches, clients, suppliers and sales relationships. It was designed to demonstrate relational database design and practical business analysis using SQL.

## Business Goal
The goal was to build a structured relational database and use SQL to answer management questions about sales performance, client value, employee contribution and branch activity.

## Tools Used
- MySQL
- Relational database design
- SQL analytical queries

## Database Structure
The project includes tables for:
- Employees
- Branches
- Clients
- Employee-client sales relationships
- Branch suppliers

Primary keys, foreign keys and referential constraints are used to maintain database integrity.

## Analysis Performed
- Analysed total sales by employee.
- Analysed total client spending.
- Identified high-value clients.
- Compared employee sales performance.
- Reviewed relationships between employees, clients and branches.
- Used joins to connect business entities across multiple tables.
- Used aggregations and grouped reporting to summarise performance.
- Used subqueries and CTEs to answer more advanced business questions.
- Ranked employee and branch performance using window functions.
- Created reusable views for recurring analysis.
- Added stored procedures for management-level reporting.
- Added audit and data-integrity logic using triggers.

## SQL Concepts Demonstrated
- CREATE TABLE
- Primary keys and foreign keys
- INSERT and UPDATE
- JOIN
- GROUP BY
- SUM, AVG and COUNT
- CASE
- Subqueries
- CTEs
- ROW_NUMBER
- DENSE_RANK
- Views
- Stored procedures
- Stored functions
- Triggers
- Indexes
- Data-quality checks

## Business Value
The project demonstrates how a structured SQL database can support recurring management reporting and business analysis across customers, employees, sales and branches.
